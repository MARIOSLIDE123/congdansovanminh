# CÔNG DÂN SỐ VĂN MINH – ĐẤU TRƯỜNG TRÍ TUỆ
### Ứng dụng học tập Tin học lớp 8 • Bộ sách Kết nối tri thức với cuộc sống
**Bài 4: Đạo đức và văn hoá trong sử dụng công nghệ kĩ thuật số**

---

## 🌟 Giới thiệu
Ứng dụng web tương tác hỗ trợ học sinh học tập và rèn luyện kỹ năng trở thành một Công dân số văn minh, trách nhiệm, tôn trọng bản quyền và bảo vệ quyền riêng tư.
- **Robot Tin học:** Trợ giảng công nghệ đồng hành, phản hồi cảm xúc và lời khuyên.
- **4 Khu vực học tập:**
  1. 📚 **Học tập:** Nhận diện 8 hành vi vi phạm & 8 nguyên tắc tạo sản phẩm số trung thực.
  2. 🧠 **Sơ đồ tư duy:** Trực quan hoá 4 nhánh kiến thức cốt lõi.
  3. 🎯 **Luyện tập:** 10 câu hỏi tình huống thực tế & Mini-game Phân loại Đúng - Sai.
  4. 🏆 **Đấu trường:** 20 câu hỏi qua 3 chặng gay cấn (Khởi động, Tăng tốc, Về đích) xáo trộn ngẫu nhiên.
- **Khen thưởng & Chứng nhận:** Cấp Giấy khen điện tử và mở kho 8 huy hiệu thành tích.
- **Tối ưu hiển thị:** Chuẩn màn hình 16:9 full chiều ngang và tối ưu trên điện thoại di động.

---

## 🚀 Hướng dẫn chạy cục bộ (Run Locally)

1. Cài đặt các thư viện phụ thuộc:
```bash
npm install --legacy-peer-deps
```

2. Khởi chạy ứng dụng:
```bash
npm run dev
```

3. Mở trình duyệt tại: `http://localhost:3000` (hoặc cổng hiển thị trên terminal).

4. Đóng gói bản phát hành (Production Build):
```bash
npm run build
```
